# 運用手順(個人運用版)

1 台の PC で、管理者 1 人が使うときの手順です。データはこの PC の Chrome の中にだけ保存されます。

## 1. 起動する

- フォルダの `起動.command` をダブルクリックする(簡易サーバーを立ち上げて Chrome で開く)
- 2 回目からは Chrome のブックマーク http://localhost:8080/ でも開けるが、PC を再起動した後は `起動.command` を先に実行する
- アプリらしく使うなら: Chrome のアドレスバー右端の「インストール」ボタン(または ⋮ → 保存して共有 → アプリをインストール)。Dock から単独ウィンドウで開けるようになる。この場合も PC 再起動後は `起動.command` が必要

初めて開くとき、`起動.command` が「開発元を確認できない」と止まったら、右クリック → 開く で許可する。

## 2. 最初の設定(1 回だけ)

設定画面で次を入れる。

1. 会社名
2. チーム(駐車場ビューの区画になる)。不要な「本社」は × で消す
3. 整備の種別(足りないものを追加)
4. アラートの日数(既定: 30 日以内は赤、60 日以内は黄)

サンプルデータが入っていたら、設定 →「すべて削除」で消してから始める。

## 3. 車両を一括登録する

1. 設定 →「車両を CSV で一括登録」→「テンプレート」でひな形を保存
2. Excel で開き、2 行目の例を消して、1 行 1 台で入力。必須は「ドライバー名」と「ナンバー」だけ。ほかは空欄でよい
   - 日付は `2027/3/31` の形でよい(`R9.3.31`、`20270331` も読める)
   - ステータスは 稼働中 / 修理中 / 休車 / 廃車 のどれか。空欄は稼働中
   - チームは設定で登録した名前と同じ文字にする
3. CSV(UTF-8)で保存。Excel では「CSV UTF-8(コンマ区切り)」を選ぶ
4. 設定 →「読み込む」(または車両台帳の「CSV 読み込み」)で選ぶと、登録前に内容の一覧と問題点が出る。問題があれば直して読み込み直す
5. 同じナンバーの車両があれば上書きになる。空欄の項目は今の値を残す(車検日だけ更新、などに使える)

## 4. 日々の入力

| いつ | どこで | 何を |
|---|---|---|
| 異常・傷を見つけた日 | 車両詳細 →「異常を登録」 | 場所 → 左右前後 → 図をクリック。写真を撮っておく。事故なら「事故記録として残す」にチェック |
| 修理・整備が終わった日(請求書が来た日) | 整備記録 →「整備を記録」 | 種別・費用・走行距離・次回の目安。車検は「車検」種別で記録すると満了日が台帳に入る |
| 車を修理に出した日 | 車両の編集 → ステータス「修理中」 | 代車があれば代車欄に入れる。戻ったら詳細の「代車を返却して稼働に戻す」 |
| 月初 | ダッシュボード | 要対応・注意の件数を見て、車検・保険の手配を進める |

## 5. バックアップ(週 1 回・必須)

- ダッシュボードに黄色の「バックアップを書き出してください」が出たら、ボタンを押す(7 日以上空くと出る)
- `車両管理バックアップ_日付.json` がダウンロードに入るので、会社の共有フォルダか外付けディスクに移す。写真も入っている
- 復元: 設定 →「バックアップを読み込む」。別の PC に移すときも同じ
- Chrome の「閲覧履歴データの削除」で「Cookie と他のサイトデータ」を消すとアプリのデータも消えるので注意。消してしまったらバックアップから戻す

## 6. 困ったとき

- 画面が古いまま: Cmd + Shift + R で再読み込み
- 「このサイトにアクセスできません」: サーバーが止まっている。`起動.command` をもう一度実行
- 入れた覚えのない車両が並ぶ: サンプルデータが入っている。設定 →「すべて削除」
