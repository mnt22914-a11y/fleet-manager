## 車体の図(2D・5 面)

- 2026-10-19 に 3D(Three.js / Blender)をいったんやめ、2D の 5 面図(左側面・右側面・上面・正面・背面)に作り直した。3D のコードは git 履歴(コミット 5bc6b75 まで)に残っている
- 本体は `js/views2d.js`。寸法 `D` は三面図(reference/)のメートル値。各面の部位は `shapes` 配列で定義し、`viewParts` がどの面にどの部位が描かれているかを持つ
- 部位の一覧は `js/logic.js` の PARTS(`onBody: false` の部位は図の下のチップで表す)
- 異常のある部位は赤 + 件数の脈打つ印、選択中は青枠。面ごとに「異常 n 件」を見出しに出す

## 動作確認のやり方(ヘッドレス Chrome)

家計簿アプリの `tests/cdp.mjs` を流用した手順。概要:

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --remote-debugging-port=9333 \
  --user-data-dir=/tmp/chrome-prof --window-size=1440,1000 \
  --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader \
  http://localhost:8080/ &
# あとは CDP(Page.captureScreenshot / Runtime.evaluate)で画面を撮る
# 3D の視点は window.__van3dView = { yaw, pitch, radius } で指定できる
```
