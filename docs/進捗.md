## 車体の図(2D・5 面、図面画像をそのまま使用)

- 2026-10-19 に 3D(Three.js / Blender)をいったんやめ、2D の 5 面図(左側面・右側面・上面・正面・背面)にした。3D のコードは git 履歴(コミット 5bc6b75 まで)に残っている
- 図は reference/ の図面画像を切り出した `img/side.jpg`・`front.jpg`・`rear.jpg`・`top.jpg`(top は前が上になるよう 90° 回転)。左側面は side.jpg を左右反転して使う
- img/ は `python3 tools/clean_blueprints.py` で生成する(車の外側を白に、方眼を除去、寸法線・引き出し線・窓の中の注記を個別に消す)。消す線の座標はスクリプト内に直書き。直すときは座標格子付きの画像を書き出して読む(スクリプト末尾のコメント参照)
- その上に透明な部位の領域を重ねる。領域の座標(画像ピクセル)は `js/regions2d.js`。描画は `js/views2d.js`
  - 領域を直すときは、元の表示座標(2000 幅の画像での座標)で考えて python で変換するのが楽。変換式: 元画像 = 表示 × 1.408、クロップ枠を引く、top は (x, y) → (H − y, x)、最後に縮小率を掛ける(side のみ 0.677)
  - 側面の領域は wheel_f / wheel_r / mirror / side / lamp_f / lamp_r という汎用 ID で、左右に応じて _l / _r を付ける
  - ランプは 2026-10-19 に左右前後 4 部位(lamp_fl / fr / rl / rr)に分けた。旧 'lights' の記録は store.normalize で「その他」に移る
- 部位の一覧は `js/logic.js` の PARTS(`onBody: false` の部位は図の下のチップで表す)
- 異常の登録は「場所(PART_GROUPS)→ 左右前後 → 図の上をクリックしてピン」の 3 段(app.js の attachPartPicker)。ピンは issue.pin = { view, x, y }(面のキーと 0〜1 の相対位置)
- 異常のある部位は赤の半透明、ピンのある異常は番号付きのピン、ピンのない異常は部位の中央に件数の印。選択中は青枠。面ごとに「異常 n 件」を見出しに出す。`.view-img.debug` を付けると全領域が見える(位置合わせの確認用)

## 2026-10-19 の仕様変更(本人の指示)

- 車両: 管理番号 → ドライバー名(主キー相当。重複チェックはしない)、車両名・車種は削除、車台番号 → 車両QR、拠点 → チーム(内部名は base のまま)、保険会社の電話番号を追加。store.normalize で旧データを変換
- 異常: 発見日 → 発生日。「事故記録として残す」チェックで事故欄(状況・自分・相手)が出る。ピンは issue.pins の配列(事故のときは複数、それ以外は 1 つ)。事故は「修理済み/未修理」、通常は「対応済み/未対応」と文言を変える
- 代車: vehicle.loaner。修理中のときだけフォームに出る。own は他の管理車両の id、rental はナンバーだけ。詳細のバナーと駐車場の札で表示。返却は return-loaner(status を active に戻し loaner を null に)
